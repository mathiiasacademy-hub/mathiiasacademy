TNPSC Thervu Nangaloda — Version 2
===================================
Includes:
- Responsive Tamil/English website (language toggle)
- Exam filter for Group 1, Group 2/2A, Group 4, VAO, and all TNPSC exams
- Searchable resource cards
- 3-question interactive sample quiz with scoring and reset
- Official TNPSC website link and study-plan section

IMPORTANT:
This is a static front-end website. It does not currently have user accounts, a database,
admin dashboard, live notifications, or a real PDF library. Resource placeholders are labelled
so students are not misled. Add only verified and legally shareable material. Keep exam details
updated from https://www.tnpsc.gov.in/ . This site is independent and is not affiliated with TNPSC.

Preview:
Extract the ZIP and open index.html in a browser.

Publish free using GitHub Pages:
1. Sign in/create a GitHub account at https://github.com/
2. Create a new PUBLIC repository, e.g. tnpsc-thervu-nangaloda.
3. Upload index.html to the repository root and commit the changes.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch"; select branch "main" and folder "/ (root)", then Save.
6. Wait a few minutes and open the URL shown in the Pages settings. It will usually be:
   https://YOUR-USERNAME.github.io/tnpsc-thervu-nangaloda/
7. Share that URL with students. The repository and website are public, so do not upload private data.

If you want a shorter URL like https://YOUR-USERNAME.github.io/, name the repository
YOUR-USERNAME.github.io (where YOUR-USERNAME is your GitHub username).

Free hosting is possible, but a custom domain may cost money. GitHub Pages hosts static
HTML/CSS/JavaScript; features requiring secure logins, a database, or private student data need
a backend service and careful privacy/security planning.
